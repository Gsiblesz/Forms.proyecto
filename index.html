Integración con Google Sheets

Consejo: despliega tu Apps Script como Web App y copia la URL aquí. El token permite rechazar envíos no autorizados.
¿Cómo funciona?
  • Usa "+ Agregar producto" para añadir tantas filas como necesites.
  • Selecciona el producto y la cantidad (número entero ≥ 0).
  • Al guardar, se almacenan los items localmente (localStorage).
  • Puedes exportar todo a CSV o borrar los registros guardados.
